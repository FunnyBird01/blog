# python 常用语法

## replace()
语法：
字符串.replace(old, new, count)
- `old`：**要被替换掉的子字符串（必须是字符串类型！）**
- `new`：用来替换的新子字符串（字符串类型）
- `count`【可选】：最多替换多少次；省略时，**全部匹配到的都替换**
- 返回值：**生成一个全新字符串**，原字符串不会被修改！

> Python 字符串是**不可变类型**，本身不能原地修改，replace 只会返回新串，必须用变量接收。

## 输入未知
利用try-except语句
```python
while True:
    try:
        n = input()
        print(n)
    except EOFError:
        break
```
1. `while True` 无限循环，不停执行`input()`读取一行
2. 当**没有更多输入**的时候，`input()`会抛出`EOFError`（文件结束）
3. `except`捕获这个错误，执行`break`跳出循环，程序结束
